## 三个系列到底差在哪

差别只在回中国的路由，不在机房，也不在硬件。三个系列都在洛杉矶（另外还有香港和东京机房），都是 AMD EPYC 处理器配企业级 SSD，都宣称不超售。价格差的每一块钱都花在“数据包从中国出去、再回来时走哪条路”上。

**Premium（套餐名带 Pro）**：三网回程走 CN2 GIA（AS4809），路由不降级。这是 DMIT 最贵的一档，也是国内访问最稳的一档。晚高峰（20:00–23:00）国内到洛杉矶的延迟大致在 140–180ms，长 ping 曲线平稳；同时间段普通国际线路绕路，北京到洛杉矶可能飙到 300ms 以上。

**Eyeball（EB）**：回程走 CMIN2（AS58807）或联通 AS9929。移动、联通用户体感接近 Premium，价格低一档。国内团队登后台的延迟大致落在 150–200ms，日常改页面、传图、看订单后台够用。

**Tier 1（T1）**：纯国际线路，没有中国大陆方向的优化。流量给得大、单价低，是三个系列里最适合“买家在国外、我也不需要在深夜秒开后台”的那一档。

这里有一条能直接帮你省钱的判断，很多人绕不过去：**对欧美访客来说，Tier 1 和 Premium 的访问速度几乎没有区别**。两者同在洛杉矶机房，差异只体现在到中国大陆方向的路由优化上。你的买家在纽约、伦敦、悉尼，他打开你的产品页走的是国际段，Premium 多出来的那段 CN2 GIA 对他没有意义。

## 算一遍真实成本：AN4 和 AN5 差多少

DMIT 现在同一款配置挂在两个平台上：AN4 是 AMD EPYC 9004 系列，AN5 是 9005 系列。CPU 新一点，价格也高一档，差价不是几块钱。

拿年付的两个套餐对比：

- **AN4 TINY $88.88/年 ≈ $7.4/月**，AN5 TINY $119.99/年 ≈ $10/月，同配置一年差 **$31.11**
- **AN4 Pocket $159.98/年 ≈ $13.3/月**，AN5 Pocket $203.90/年 ≈ $17/月，同配置一年差 **$43.92**
- 月付的 STARTER：AN4 $29.90/月，AN5 $38.90/月，一年差 **$108**

如果你的站是 WordPress 或者常见的外贸建站程序，跑的是 PHP + MySQL，吃的是内存和磁盘 I/O，不是 CPU 单核跑分，AN4 的 EPYC 9004 完全够用。**同配置优先选 AN4，省下来的钱够你多买一年的备份或者 CDN。** 只有当你确实要跑重计算任务，比如站内做图片批量处理、跑数据脚本，AN5 的 CPU 提升才有意义。

另一层成本差异在计费周期。年付折下来的月价明显低于月付，上面 AN4 TINY 的 $88.88/年 折合 $7.4/月，而同款按月买是另一个数量级。不确定能不能长期用，先月付一个月测线路，确认晚高峰后台不卡，再切年付，比一上来买年付然后申请退款省事。

## 下单前必须知道的五件事

**1. 退款有时间和流量两道门槛。** 3 天内可以申请全额退款，前提是这台机器用掉的流量不超过 30GB；超过 3 天但在 30 天内，按剩余价值部分退款。另外三条不退的情况要记牢：续费订单不退、同一系列产品退款累计超过 3 次不退、退款只走原路或退到账户余额（退到余额免手续费，退回原支付渠道会扣掉支付网关的手续费）。

还有几种情况官方明确不退款：IP 因为个人原因被封、被 DDoS 攻击、以“网络不够好”或“IP 地理位置”为理由申请、以及先违反条款再去支付平台发起争议。**买之前确认需求，别拿退款当试用。**

**2. 默认是 SSH 密钥登录，不是密码。** 没用过密钥的人第一次会卡在这里。下单时把公钥填好，或者看购买页有没有允许密码登录的选项；官方知识库有配置教程，照着做一次十几分钟。这一点对建站没影响，但对第一次上手的人是真实门槛。

**3. 换 IP 有免费额度，但别指望随便换。** Premium 和 Eyeball 在满足条件的情况下每 15 天可以免费更换一次 IP，其他情况 $5/次。有资料提到需要购买满 7 天后才可申请，具体以工单回复为准。**Tier 1 要特别注意**：官方条款写明，没买 IP Guarantee+ 附加项的 Tier 1 订单，不保证分配到的 IP 在中国、俄罗斯等有网络审查的地区可访问；月付周期的订单同样不做保证。买 Tier 1 又需要国内能连上，下单时把 IP Guarantee+ 勾上，省掉后面换 IP 的麻烦。

**4. 流量超了不停机，改成限速继续跑。** 这一点对外贸站很实用，促销季流量突然翻倍，网站不会直接 404，而是降速撑着。不过超量后的限速值每个套餐不一样，差距不小，买之前看清楚套餐页上“超量后”那一栏写的是多少 Mbps，别只看月流量总量。

## 哪些人不用考虑 DMIT

**做 Amazon、eBay 多账号管理的**。这类需求的核心是 IP 类型（住宅 IP、ISP IP），而 DMIT 提供的是数据中心 IP。它适合建站，不适合平台多账号这种用途，这一条官方 FAQ 里写得很直白。

**需要频繁换机房试线路的**。DMIT 的机房和套餐是绑定的，换机房基本等于换机器。同价位里，搬瓦工的一键换机房和免费快照备份更灵活，套餐选择范围也更宽；代价是网络稳定性上，DMIT 的不超售和自有 CN2 GIA 带宽在晚高峰更占优势。经常折腾线路对比的选前者，建好站不想再动的选后者。

**只想买全场最便宜的**。DMIT 的定价在同配置里不算低，它卖的是线路和资源独享。如果你的站访问量很小、买家对加载速度不敏感，市面上有更便宜的选择，没必要为用不上的线路优化付钱。
